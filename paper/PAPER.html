哥德巴赫误差场中的乘性相关

一项经验研究

摘要. 设 G(N) 是一个光滑加权的平衡哥德巴赫计数，e(N) = c_φ𝔖(N) − G(N) 是它相对 Hardy–Littlewood 主项的偏差，ε(N) = e(N)/(c_φ𝔖(N)) 是相对误差，其标准差在 N ≈ 3×10⁴ 处为 0.086（即配对计数噪声的量级）。我们报告误差场 ε 的一条可复现的经验规律：它在 乘法伸缩下的两点相关

c(k) = corr( ε(N), ε(kN) ),      N 取遍一个窗口内的全部偶数，

满足：(i) 符号确定：sign c(k) = (−1)^{ω(k)} 在 31 个 2 ≤ k ≤ 49 的整数中有 28 个成立， 唯一显著的例外是 k=26（2σ）；(ii) 素数处的幅度 ≈0.135，但并非常数：九个素数点 跨 −0.158 … −0.101，χ² = 72.8（8 自由度，p = 1.4×10⁻¹²）；(iii) 对互素的 (k₁,k₂)=1 近似乘性（10 个检验中 6 个在 1σ 内，其余为 1.1σ, 2.4σ, 3.2σ, 4.0σ； 六个中有三个是素数平方的情形，故我们不声称平方自由）；(iv) 不满足完全乘性延拓 （c(p²) 为负，离 c(p)² 有 3–13σ，p ≤ 5 时 7–13σ），所以"Liouville 型"读法 c(k)=α^{ω(k)}λ(k) 被定量否定；(v) 在 10⁴ 到 10⁹ 的每个素数比上都存在，未分辨出 衰减律：窗口间散布（±0.025）是窗内误差的三到四倍。

这一测量不是归一化的产物（k=2 时它与 corr(G(N),G(2N)) 重合），不是权重形状的产物 （五种不同权重），不是 N 中位置的产物（效应在宽度 40 的块内仍成立），不是 N 的因子 分解的产物，不是随机素数模型的产物（−0.017±0.025），也不是任何平滑趋势的产物。

但误差场不是白噪声，这是一个独立的规律：它的自相关在不被 30 整除的滞后上 ≈0 （2σ 内），而在被 30 整除的滞后上为正——ΔN = 210 处 +0.216、630 处 +0.238、 2100 处 +0.146——对应一个携带约 18% 方差的漂移的周期-30 分量，且它不是残类均值 （§5.9、§5.10）。相应的误差棒比 1/√M 给出的大约 1.5 倍。

我们还记录一个使该测量令人意外的结构性障碍：G(N) 用到 [N/3,2N/3] 中的素数， 而 G(kN) 用到 [kN/3,2kN/3]，当 k=2 时这两个区间不相交；而且四个线性形式 (n, N−n, n′, 2N−n′) 的四点局部密度在每个素数处精确分解。因此任何"局部密度正确 + 位置独立"的素数模型都会预测协方差为零。实测的 −0.14 因而只能有两种读法：要么是估计量 伪影，要么是素数四点相关的真实长程缺陷。本文的对照把前者逐一关闭。

1. 引言

1.1 对象

设 Λ 为 von Mangoldt 函数，φ 为一个在 [1/3,2/3] 上光滑、在端点为零的权重（默认 φ = cos²(3π(u−1/2))，故 φ² = cos⁴，c_φ = ∫cos⁴ = 1/8 = 0.125）。定义

G(N) = Σ_{n+m=N} Λ(n)Λ(m) φ(n/N)φ(m/N)                          (1.1)

因为 φ 对称且支撑在 [1/3,2/3]，G(N) 只统计平衡的素数幂对：两端都落在 [N/3,2N/3] 内。Hardy–Littlewood 预测

G(N) ≈ c_φ 𝔖(N),      𝔖(N) = 2C₂ ∏_{p|N, p>2} (p−1)/(p−2),
C₂ = ∏_{p>2} (1 − 1/(p−1)²) = 0.6601618158…                      (1.2)

记

e(N) = c_φ𝔖(N) − G(N),        ε(N) = e(N)/(c_φ𝔖(N))           (1.3)

ε 是本文的研究对象。在 N ≈ 3×10⁴ 处 sd(ε) ≈ 0.086，与 √N 标度下的配对计数噪声 一致。

1.2 测的是什么

对每个整数 k ≥ 2 定义

c(k) = corr( ε(N), ε(kN) ),      N 遍历窗口内全部偶数                (1.4)

窗口固定为 [N₀, 1.3N₀]（相对宽度固定），M 为窗口内偶数的个数。所有相关系数都用块自举 给误差棒（块长 40，400 次重采样）。

为什么这个量值得测。 如果 ε 是"白噪声 × 一个缓慢变化的尺度"，那么 c(k) ≈ 0 对一切 k。如果 ε 携带任何与素数结构有关的跨尺度信息，c(k) 就会非零，而且它的 k-依赖会 直接反映那种结构的乘法性质。

2. 估计量及其标定

2.1 三套独立实现

§4 的测量由从零写起的代码产生，独立于任何既有实现：

  • lab/tool.py — 向量化 NumPy；lab/ngb.py — JIT（numba）版本，快 13 倍；
  • lab/fast2.py — 多进程驱动，python fast2.py --n0 12000 --m 40000 --k 2,3,6。

三套实现在 N = 2000, 2018, 4002, 4006 上逐位一致到 10⁻¹⁰。注意：N=2000 和 4002 处 Λ(N/2) = 0，所以它们不检验半区间求和的边界项；N=2018（N/2 = 1009 为素数） 才检验，两者差 47.84（主项的 4.4%）。这个检查点必须包含 Λ(N/2) ≠ 0 的情形。

2.2 主项的标定

sanity = ΣC/Σmain 必须在 1 的 1% 以内，否则该窗口的 c(k) 不予引用。这条规则来自 一次事故：局部因子在 N ≡ 2r_p (mod p) 时曾取了 p−2 而非 p−1，主项系统性偏 6–10%，使得 c(k) 的散布被放大 4 倍、均值被推到任意方向。

2.3 零模型的选择标准

一个可用的零模型必须同时满足四条：

  • 密度剖面：1/log n，不是常数；
  • 方差：sd(ε) 在多个尺度上与真实值吻合；
  • 主项：可解析计算，sanity 通过；
  • 可扩展：能在 10⁶ 以上计算。

§5.8 的 α = 0.56 筛模型是唯一同时满足前三条的。

2.4 测量本身的稳定性

同一 N₀ 用不同的 M 会给出不同的 c(k)，差异可达 2σ：N₀ = 12000 处 M = 2000 给 c(2) = −0.021，M = 10⁵ 给 −0.065。任何 c(k) 结论必须 M ≥ 2×10⁴。

2.5 两点相关的对照

Σ_{n≤X} Λ(n)Λ(n+h) 对偶数 h 的实测值与 𝔖(h)(X−h) 的比值在 0.9886–1.0178 之间 （h = 2..80）。这条对照证明 𝔖 的实现是正确的。注意主项必须写 𝔖(h)(X−h)， 写成 𝔖(h)X 会留下一个线性斜坡，把任何相关都推到 ≈ +1。

4. 相关场

4.0 两种窗口约定，用在不同表里

窗口进入了本文的每一个数字，而本文用了两种约定。这是表述上的缺陷（不是测量上的），但必须写明。

  • 固定个数：[N₀, N₀+2M]，M 个连续偶数，相对宽度随 N₀ 增大而缩小。 这是 §3.1、§4.10 的尺度扫描、以及 §5.8–§5.11 用的约定（校准筛零模型、ω 记忆、零点分量 都是从 N₀ 起取 M 个连续偶数）。
  • 固定相对宽度：[N₀, 1.3N₀]，始终是 N₀ 的 30%。这是 §4.1 为 c(k) 表声明的约定。

两者不可互换。N₀ = 2×10⁵ 处，M=2000 的固定个数窗口只占 N₀ 的 2%，而 [N₀,1.3N₀] 占 30%——差十五倍。c(k) 依赖窗口（§4.8 显示仅五种权重形状之间就有 0.031 的散布），所以 不同约定的两个数字不可比；本文没有在未声明的情况下做过这种比较。

4.3 S1：符号律（成立）

三十一个值中有二十八个满足

sign c(k) = (−1)^{ω(k)}                                          (4.1)

ω(k) 是不同素因子的个数。三个例外是 c(26) = −0.0144（2σ）、c(28) = −0.0014 （0.2σ）、c(30) = +0.0027（0.4σ），只有第一个统计显著。

特别地，符号不是 λ(k) 的符号：k = 4, 9, 25, 49 时 ω(k)=1 且 λ(k)=+1， 而 c 在四个情形下都是负的。规律 (4.1) 是全文最稳健的陈述：它在五种权重下成立（§4.8）， 在七个尺度窗口下成立（§4.10）。

28/31 到底有多强？ 若 31 个符号是独立的公平硬币，P(X ≥ 28) = 2.3×10⁻⁶ （P(X ≥ 27) = 1.7×10⁻⁵）。它们并不独立——31 个相关都算自同一个场——所以这是一个 量级指示，不是检验。它排除的是"抛硬币"式的来源；它给不出标定后的显著性，后者只有 §4.2 的 块自举和 §5.8 的筛零模型能给。

  • 在平方自由的 k 上，(4.2) 与数据相容：符号对（28/31），量级在 1.1–1.5 倍内， §4.5 的乘性检验九个乘积中六个通过。真正排除 (4.2) 作为精确定律的是 α 在素数间的 散布（χ² = 72.8，§4.4），不是素数幂的值。

4.7 一个进一步的理论约束：有理比

c(k) 只在整数比上有定义。若假设"ε 在乘法半群上是平稳的"，则 c 必须能延拓到有理比。 实测的矛盾：c(3) 与 c(2) 不同，但若存在平稳性，corr(ε(2N), ε(3N)) 应同时等于 c(3/2) 与 c(3)/c(2) 的某个组合——这两种读法给出不同结果（差 0.05，2σ）。 所以"锥平稳"太强，可能根本不存在。§8 会给出这条的严格形式。

经典读法认为哥德巴赫误差由 ζ 的零点通过显式公式驱动。这可以直接检验，而它在统计上 （不是某个数上）就被否掉了。

我们用 Riemann–Siegel 主项的变号定位了高度 40 000 以下的 48 900 个纵坐标，再用向量化 二分细化，并在窗口 N = 12000+2i（i < 15000）上构造显式公式能产生的两个场：

L(N) = Σ_j N^{iγ_j}/γ_j                            （一个零点：密度型）
P(N) = |L(N)|² = Σ_{j,k} N^{i(γ_j+γ_k)}/(γ_j γ_k)   （两个零点：配对型）

关于零点表的两个说明：Riemann–von Mangoldt 公式预言 40 000 以下有 49 395 个零点，所以 约 1% 被漏掉（在 Riemann–Siegel 余项使主项变号的地方；把搜索网格从 0.2 加密到 0.005， 计数从 48 533 升到 48 901 后不再变化）；而且纵坐标是主项的零点，首个零点误差 O(0.4)、 在 t = 4×10⁴ 附近约 0.01。两点都不影响下面的结论，因为它关于场的光滑性：

5. 为什么这个测量令人意外

5.1 先排除平凡解释

主项：ΣC/Σmain 在 0.99–1.01 之间（§2.2）。归一化：k=2 时 c(2) 与 corr(G(N),G(2N)) 重合到 0.001。估计量：块自举、Spearman、截尾、逆方差加权都给出同一 结论。这些都不解释效应，但必须先关闭。

5.2 障碍：两个计数用的是不相交的素数

k=2 时两个求和是

G(N)  = 2 Σ_{N/3<n<N/2} Λ(n)Λ(N−n) φ²(n/N),      n, N−n ∈ [N/3,2N/3]     (5.1)
G(2N) = 2 Σ_{2N/3<n<N} Λ(n)Λ(2N−n) φ²(n/(2N)),   n, 2N−n ∈ [2N/3,4N/3]  (5.2)

而两个素数区间 [N/3,2N/3] 与 [2N/3,4N/3] 不相交（只在 2N/3 一点相接，而那里权重 四阶为零）。对每个 k>1 都一样：和为 N 的对跨 N/2、落在 [N/3,2N/3]；和为 kN 的对 跨 kN/2、落在 [kN/3,2kN/3]；只要 k ≥ 3/2 这两个区间就不相交。

所以我们要测相关的两个随机变量，是同一素数配置的不相交两片的函数。这不是约定， 是 n+m=N 的算术加上平衡支撑逼出来的。

5.3 四点局部密度精确分解

把 (5.2) 的变量记作 n′，考虑四个线性形式

n,   N−n,   n′,   2N−n′        (n ∈ [N/3,N/2],  n′ ∈ [2N/3,N])

由 Hardy–Littlewood，四者全为素数的四元组密度在 o(1) 意义下是 𝔖₄/log⁴N， 𝔖₄ = ∏_p σ_p，σ_p 是模 p 的容许配置数除以"随机"计数。计算给出

𝔖₄ = 𝔖₂(N) · 𝔖₂(2N)      对每个素数 p 精确成立

即四点局部密度 = 两个两点局部密度之积。于是任何"局部密度正确 + 位置独立"的素数模型 都给出

Cov( G(N), G(2N) ) = 0        （在 o(1) 误差内）

5.4 这意味着什么

实测的 c(2) = −0.14 只能是两种东西之一：

先说清 0.14 是什么：它是标准差乘积 sd(ε(N))·sd(ε(2N)) 的 14%， 不是任何四点密度的 14%——密度本身由 §5.3 匹配到机器精度。

(A) 估计量伪影 —— ε 的构造方式把两片耦合起来了； (B) 素数四点相关的真实长程缺陷 —— "局部密度 + 独立位置"这个启发式在这里失效。

§5.5 的对照逐一关闭 (A)。

5.6 决定性检验

若 ε 的耦合来自"N 与 kN 的算术相关"，那么用一个与 N 无关的随机集代替素数， 效应应该消失。§5.8 给出的校准零模型正是这个检验。

5.7 四变量求和，实际计算

(1) 分解精确，用枚举验证。 对 N ∈ {12000, 12002, 12006, 12010, 30030, 23100} 与每个 p ≤ 500 的素数（95 个素数、共 570 对），把 (n, N−n, n′, 2N−n′) 的联合局部计数按 Z_p² 上全部 p² 个剩余对枚举，再与两个边际计数之积比较：

max |joint / (marg₁ · marg₂) − 1| = 0.000e+00      （570/570 对，精确）

理由一行：p | N 时两侧各只排除 0，计数都是 (p−1)²；p ∤ N 时两侧各排除两个剩余， 计数都是 (p−2)²。所以四点奇异级数恒等分解，Hardy–Littlewood 的预言 (5.7) 不是"很小"， 而是 0。

(2) 实测协方差。 Cov(ε(N),ε(2N)) = −8.27×10⁻⁴，sd·sd = 5.91×10⁻³，即 c(2) = −0.1400（M = 15000）——这是 §4.2 的直接估计量，不是四变量计数的副产品。 真正的检验是 §5.8。

5.8 一个校准的筛型零模型

§5.7(b) 曾记录"筛型模型能产生负的 c(2)，但标定不了"：它的场方差是真实值的五倍。 这个缺口已经补上。

旧失败的原因。 筛界固定为 P = √X：对每个 n 都用同一批素数各剔除一个剩余类， 所以密度是常数 ∏_{p≤P}(1−1/p) ≈ e^{−γ}/log P，而不是 1/log n。在实际使用的窗口里 （n ≈ 4×10³–2.8×10⁴，log n ≈ 8.3–10.2），有效指数 α_eff = log P / log n ≈ 0.79， 密度只有 1/log n 的 e^{−γ}/(0.79 log n) ≈ 0.71–0.81——是 20–30% 的亏，不是 √n 界会给出的 12% 盈；而亏会放大相对涨落。若把筛界改成 n^α，则 ∏_{p≤n^α}(1−1/p) ≈ e^{−γ}/(α log n)，于是

α = 0.56   ⟹   密度常数 e^{−γ}/0.56 = 1.0027 ≈ 1.000

实测：α = 0.50 给 1.1241，α = 0.56 给 1.0076，α = 0.62 给 0.9126。

这说明什么。 一个主项正确、密度剖面正确、方差准确到 9% 的随机筛，符号对、典型量级 只有观测值的二十分之一。这是"该效应不是筛出来的集合的通性"的证据——但 p ≈ 1.7×10⁻² 不构成拒绝。要到 4σ 需要约 10⁵ 个种子。

5.11 零点分量：无拟合的计算

§4.12 的场是由零点的显式公式直接构造的。另有一条独立的路：权重不该拟合——它们由权重的 Mellin 变换固定。于是这个问题可以不用任何拟合就解决。

预言。 计数对素数密度涨落的线性响应是 e(N) ~ Σ_ρ N^ρ/ρ · M(ρ)，其中

6. 被否定的描述

6.1 不是 log k 的函数

若 ε 是零点的"少数频率"叠加，c(k) 应是 log k 的低频函数。用 1–4 个频率拟合： R² = 0.31, 0.54, 0.58, 0.61。作为"少数频率"模型被否定（但任意函数 F(log k) 未被排除）。

6.2 不是 Liouville

corr(ε, λ) = 0.003。若 ε = λ·Z，应为 ±1。排除。

6.3 一个机制必须产生什么

c(k) 必须：符号按 (−1)^{ω(k)}、在素数处 ≈ −0.135、近似乘性、在素数幂处为负、 在 10⁴–10⁹ 上不消失。任何机制都必须同时满足这五条。

6.4 乘积模型 1+ε = ∏_p(1+ξ_p)

预言符号翻转，实测没有。排除。

6.5 单因子残差模型

残差之间仍相关（0.15）。排除。

6.6 乘法格上的 Markov 结构

六个偏相关中有五个非零（3–8σ）。排除。

6.7 Dirichlet 特征

q=15 处 corr = 0.19，但那是 2σ 噪声。排除。

6.8 四变量局部因子（+25%）

符号和量级都不对，已被 §5.3 的精确分解取代。

6.9 退化构型

贡献恒为零。确认。

6.10 窗口素数质量

corr = −0.018（后来 +0.105，随窗口而变）。不是驱动因素。

6.11 三元与多项式权重（开放，不是证据）

三元的符号族相同但幅度不同。这些具体幅度已撤回：产生它们的那份驱动把三元计数按 N 索引，而分母按 kN 求值，所以那些数不是 corr(ε(N), ε(kN))；随 k 单调漂移就是索引 错位的特征。定性结论不依赖它们：三元场是密度主导的（噪声 0.0070，其中配对通道只占 0.0025），二元场是配对主导的，所以三元是错的对照，而不是独立证据。

7. 讨论

7.1 什么在什么条件下成立

本文没有定理。以下是带明确适用范围的经验陈述，每条都取它最可辩护的读法。

断言成立到什么程度范围与削弱条件
S1 符号律（28/31）作为抛硬币指示 p ≈ 2×10⁻⁶，但不独立31 个相关共享同一个场；标定后的显著性只有 §5.7(3) 那个（3σ–15σ）和 §5.8 的筛零模型（≈2σ）
素数处相关为负3σ–15σ（取决于是否把素数视为分解化系综的一次抽样，§5.7(3)）；校准筛零模型的 1.7 百分位（§5.8）不引用 1/√M 给出的更大数字：§5.9 表明那些误差棒太小，因为场不白
S6 权重独立五种权重，c(2) ∈ [−0.163,−0.132]第六种支撑不同的权重可能不同
高斯、亚尾kurt = 3.00，尾到 3.3σ超过 3.3σ 未测
标度律 (3.1)三个尺度上 ±3%三个点不是定律
ω 梯度（§5.10）数据侧 12σ模型侧未测；N-独立性在 N < 12000 未测
四点分解（§5.3）精确到机器精度13 个素数上数值验证；解析恒等式是初等的

本文不做两个陈述。 (i) 四点障碍强制观测值——§5.3 只说明分解化的模型预测零， 而落在这个类之外的机制（耦合位置而非密度的）不受它约束。(ii) 零点已被排除——§5.11 说明 它们给出量级正确的分量但不组织 c(k)；完全的排除需要一个这里没做的计算。

关于多重性。 分析看了很多数字：31 个 k、五种归一化、五种权重、七个尺度（§4.10），以及每一处 的自动选择（块长、截尾）。对 31 个 k 做 Bonferroni 会把 2.3×10⁻⁶ 变成 7×10⁻⁵——不改变 任何结论；但真正需要修正的不是 k，而是那些在看到数据之后才做的选择（引用哪种归一化、 哪个窗口、哪个尺度）。这些无法从论文里穷举，诚实的说法是：报告出的显著性带着一个未量化的 向下修正。能扛过这个修正的是两样东西——符号律的形状（一个模式，不是单个检验）和 ω 梯度的形状（12σ，也是一个模式）。

可证伪的预言。 符号律应在更大的 k 和 N 上继续成立；c(2) 应对一切 N 为负； ω 梯度在模型侧被测时应保持；T2 的四变量求和应恒为零（所以它检验代码，不检验物理——见 §5.6）。

7.2 主要的未完成测量

关于幅度的一切（α、乘性、素数幂的值）都建立在单个窗口上。§4.10 的尺度依赖表明这不 够。下一步是一个专门的研究：固定相对宽度的窗口，六个尺度从 10⁴ 到 3×10⁶ 各取 M ≥ 3000，同时测量全部 k ∈ {2,3,4,6,9,10,12,15}。这需要附录 B 的实现（每个尺度 一分钟）。

7.3 与 Li–Liu 条件恒等式的关系

附录 A 表明，该预印本的谱假设等价于算子范数界 ‖T_N‖ ≤ δ_N， δ_N = √(𝔖/N)(log N)^{3/2}，而单独的 GRH 只给出 ≪ (log N)²。同时 (3.1) 给出真实误差 尺度 0.33 log N/√N，于是

δ_N / (e 的真实 sd) = 3.0 √(𝔖(N) log N) ≈ 17–20    在 N = 10⁷ 处      (7.1)

这个比较必须小心读：(3.1) 是单个二次型 ⟨T_N v_N, v_N⟩ 的尺度，而假设 R 界的是 算子范数。由于 ‖T_N‖ ≥ |⟨T_N v_N, v_N⟩|/‖v_N‖²，数据只能从下方约束范数。即使在最有利 的读法下——范数与二次型同量级——它也落在 δ_N 之下 √log N；同样可能远大于。

所以经验规律与假设 R 相容，但不给它任何支持，也不能用来论证该假设"几乎成立"。 任何说经验规律"支持"该条件证明的断言都是没有根据的；说它"推翻"该证明同样没有根据。

附录 A. Li–Liu 预印本：验证了什么，错在哪里

A.1 架构

预印本把 Goldbach 问题化为一个算子 T_N 的范数估计，假设谱半径满足某个界（假设 R）， 由此推出哥德巴赫。这个架构本身是自洽的；问题在于假设 R 的来源。

A.2 验证过的

  • G = D − P 的投影恒等式（数值到 10⁻¹⁴）。注意它只对 (nm,N)=1 的和严格成立： 无限制的 G 与它相差 n=m=p^k, p|N 的项，共 O(log N) 个、每个 Λ²φ²， 合计 O(log²N)，是 o(σ)，被 (A.5) 的误差项吸收；该恒等式是对受限计数陈述的， 对无限制计数只在该精度下使用。
  • c_φ = 1/8、I4 = 0.091146、C₂ = 0.6601618158 等常数；
  • 四点局部密度的分解（§5.3）；
  • 特征标正交性在 N 上重建互素条件。

A.3 一处笔误与一个常数

预印本中一处 Hermitian 对称性写成 ⟨Tv,w⟩ = ⟨v,Tw⟩，缺了共轭横线；不影响论证。 I4 的数值正确。

A.4 评估

假设 R 没有被证明，也没有被数据支持。它等价于一个比 GRH 更强的算子范数界 （见 §7.3 的 17–20 倍差距）。预印本的价值在于把哥德巴赫化归为一个清晰的谱问题， 不在于解决了它。

附录 C. 方法上的教训

  • 先看 sanity = ΣC/Σmain。偏离 1 超过 1%，就不许看 c(k)。主项错 6–10% 会把 c(k) 的散布放大四倍，并把均值推向任意方向。两处早期结论就是因为这个错的。
  • 任何 c(k) 结论必须 M ≥ 2×10⁴。同一 N₀ 用 M=2000 与 M=10⁵ 可以差 2σ。
  • 不要用论文表格里挑出来的点做拟合。本工作中四次"找到了解释"都在扩大样本后碎掉： c(k)=μ(k)α^{ω(k)}（29 点 R=0.96 → 大 N 崩）、随机筛（12 种子 → 120 种子，1.7 百分位）、零点分解（6 点 R=0.94 → 49 点 R=0.33）。
  • 主项写 𝔖(h)(X−h) 不是 𝔖(h)X。后者留下线性斜坡，把任何相关推到 ≈+1。
  • 半区间求和不能重复计 k=N/2 项。偶数 N 时 Λ(N/2)² 会被算两次。
  • 任何零点谱计算，先验 M(1) = c_φ。权重在 ρ = 1 的 Mellin 变换必须还原常数 c_φ = 1/8。这条能抓住 §5.11 实际犯过的两个错：误用多项式权重（M(1) = 0.406）、 以及把 cos⁴(3π(u−1/2)) 延拓到 [0,1]（那里有两个峰而不是一个，M(1) = 0.375）。 两种错都给出看似合理的 c_z，两种都是错的。
